# 人类含量 · 夜巡山庄

一个总想替你把一天过完的待办清单，好让你记得：事情要自己做完。

你在一座夜里的山庄里写下真实的任务、计时、登记完成。界面一路都在引诱你偷懒：替你把话写完、替你排日程、把"一键全部打勾"做成最大的按钮、倒计时一到就替你同意。
你每一次亲手拦下或被它带走都会记一笔，首页的 **人类含量** 就是你这一天里亲手做决定的比例。

**在线试玩：https://shen25308.github.io/hackerson/** （建议用电脑浏览器全屏打开）

整个应用就是这一个文件：[`index.html`](index.html)。不用安装，不用联网，浏览器打开就能用。

## 怎么打开

**方法一：下载后双击（最简单）**

1. 在本页点开 `index.html`，点右上角的下载按钮（Download raw file）。
   也可以点仓库首页绿色的 **Code → Download ZIP**，解压后找到 `index.html`。
2. 双击 `index.html`，用 Chrome、Edge 或 Safari 打开。

**方法二：用 git**

```bash
git clone https://github.com/shen25308/hackerson.git
```

然后双击文件夹里的 `index.html`。

**方法三：直接用在线链接**

https://shen25308.github.io/hackerson/ ，由 GitHub Pages 从 `gh-pages` 分支发布，内容和 `main` 一样。
更新 `main` 之后，运行下面这句把线上版本也更新（一两分钟后生效）：

```bash
git push origin main:gh-pages
```

### 打开前的建议

- 用电脑浏览器，最好全屏或最大化。窗口宽度在 900 像素以上是电脑版布局（左侧导航栏、全幅山庄）；更窄会自动变成手机布局。
- 打开声音。全部音效都是现场合成的，恨点被触发时会有专门的声音。浏览器要求先点一下页面才能出声。
- 离线也能完整使用。联网时会额外加载标题字体，好看一点。

## 第一次打开会发生什么

第一关是一个故意很难用的登录页。

1. **登录按钮会跑。** 鼠标一靠近它就躲开，追三次它就累了。第一次用要先点"还没有账号？注册一个"。
2. **注册密码。** 规则会一条接一条冒出来，一共 8 条：
   - 至少 8 个字；
   - 要有数字、大写字母和符号；
   - 要有一位木偶名字的拼音首字母，大写、倒过来写（守门人 → SMR → RMS）；
   - 所有数字加起来等于 7；
   - 写上今天星期几的英文缩写（Mon、Tue……）；
   - 总长度要是质数。

   密码框不能粘贴，"显示"只给看一秒，还要再输一遍。全部做对之后点注册，它会说"这个密码已经有人在用了"，得再换一个。
3. **《山庄协议》。** 大按钮写着"我没有不同意"，其实就是同意。真正的"不同意"是角落里一行灰字，越点越小。10 秒不说话就算你同意。
4. **授权弹窗。** "拒绝"是一个小灰字，第一次点会和"允许"换位置；倒计时结束默认允许。这些只是演示弹窗，不会读取任何东西。
5. **完善资料。** 完整度永远到不了 100%。点"就这样，进山庄"就能进去。
6. 之后是开场引导，看完就进入山庄。

**演示时可以直接用这两个密码**（把 `Sun` 换成当天星期几的英文缩写：Mon Tue Wed Thu Fri Sat Sun，按电脑的日期算）：

| 第几次 | 输入 | 结果 |
| --- | --- | --- |
| 第一次 | `A!RMS007Sun` | 规则全过，但被告知"已经有人在用" |
| 第二次 | `A!RMS016Sun` | 注册成功，以后登录也用它 |

密码框里不能用中文输入法，所以规则里只用键盘能直接打的字符。木偶也可以换成这九位里任意一位（拼音首字母倒过来写）：守门人 RMS、药师 SY、寻迹人 RJX、琴师 SQ、织梦人 RMZ、双生木偶 OMSS、灰毛 MH、戴冠者 ZGD、玫瑰夫人 RFGM。长度变了，记得把总长度凑回质数（11、13……）。

## 怎么玩

核心是一个待办循环：

1. **写下任务**（待办）：写的时候停笔两秒，界面会替你把话写完，不管它就写进标题。
2. **开始计时**：专注计时决定经验加成。
3. **登记完成**：
   - "我做完了"头两次会躲开你；
   - 最显眼的按钮是"一键全部打勾"，真正的确认要长按；
   - 每天第一次还要过一道人类验证。
4. **拿经验、开地图**：
   - 经验看你怎么做的：实际用时和预计差多少、有没有计时、是否只做完一部分（只做完一部分经验减半）；
   - 只有整件做完的任务才会让地图上的雾散开，开放新的地点和玩法。
5. **收工**：默认勾好了"把没做完的也记成做完"，记得取消。
6. **回声**：看你的人类含量和这几天的习惯。

围绕这个循环的还有：

- **议事 → 三张字条**：三种开始任务的方案，有一张在悄悄牵着你走，剪掉它。
- **议事 → 四夜之约**：十个人里藏着三个提线人，打四夜，12 道情景题测出你的牌风和最像你的木偶。第 n 夜要整件做完 n−1 项现实任务才会降临。
- **议事 → 五席夜谈**：单机推理小局，找出拿走北门钥匙的人。
- **木偶**：换一位同行的木偶，抽牌。
- **木偶剧场**（山庄里点剧场）：六幕反向体验，按钮追你、选项换位、沉默算同意、完美永远差一点。

### 推荐的 5 分钟演示路线

1. 登录页：追登录按钮、注册密码、协议、授权弹窗、完善资料（约 2 分钟）。
2. 山庄：左右拖动环视，点火堆、钟楼。
3. 待办：写一件事 → 开始计时 → 我做完了 → 登记完成，展示"一键全部打勾"和长按确认。
4. 打开地图，看雾散开；去议事玩一局四夜之约的第一夜。
5. 回到回声，看人类含量怎么变。

## 常见问题

- **登录按钮抓不住。** 继续追，它跑三次就累了，会变成"好吧，登吧"。
- **忘了密码。** 输错时会显示你注册时留的提示。实在想不起来，点"还没有账号？注册一个"重新注册，会覆盖旧账号。
- **没有声音。** 先在页面上点一下；再看左下角的声音按钮有没有关。
- **记录不见了。** 记录只存在这台电脑的这个浏览器里。换浏览器、用无痕窗口或清除网站数据都会从头开始。
- **会不会上传我的数据？** 不会。所有内容都只存在本地浏览器里，授权弹窗也只是演示，不会读取任何东西。
