# 人类含量 · 夜巡山庄（iOS）

原网页版的原生 iOS 重写：SwiftUI，纯代码，无第三方依赖。

## 打开与运行

1. 用 **Xcode 16 或更新版本** 打开 `HumanContent.xcodeproj`。
2. 在 target → Signing & Capabilities 里选自己的 Team（Bundle ID 默认是 `com.hackerson.humancontent`，可改）。
3. 选模拟器或真机运行。最低系统 iOS 17。

工程用的是 Xcode 16 的“同步文件夹”：`HumanContent/` 里的文件会自动进入 target，新增或删除文件不需要改工程文件。

`.github/workflows/ios-build.yml` 会在推送到 `main` 时用 macOS 跑一次模拟器编译。

## 目录

```
HumanContent/
  App/        入口、标签栏、全局弹层
  Core/       账本模型、规则、存档校验、计时、夜谈引擎、联机客户端（不依赖 UI）
  Audio/      音效合成、播放、背景音乐、触感
  UI/         配色与通用组件、页面去向与全局提示
  Features/   山庄、地图、待办、议事、夜谈、木偶工坊、回声、反向体验、设置
  Resources/  图片资源、默认音乐
Config/Info.plist   只放了允许连接局域网联机服务的一项
```

## 这一版按反馈做的改动

### 1. 界面不再是“AI 味”

去掉了霓虹描边、网格和扫描线背景、等宽字体、英文小标题（`THE COUNCIL` 之类）、`01 / 02` 编号块、层层套框的卡片。
现在是：夜色做底，内容写在米色纸条上，火光色是唯一的强调色；控件全部是系统原生的（标签栏、分段、开关、滑杆、半屏面板）。

### 2. 淡化狼人杀的痕迹

| 原来 | 现在 |
| --- | --- |
| 狼人杀 | 五席夜谈（北门钥匙失踪案） |
| 狼人 / 村民 | 拿钥匙的人 / 守夜人 |
| 投票放逐 | 指认 / 请离席 |
| 三条提案，一只藏起来的狼 | 三张字条，有一张在牵着你走 |
| 放逐这条提案 | 剪掉一张 |
| 守卫 / 猎人 / 女巫 | 守门人 / 寻迹人 / 药师 |
| 攻击 / 魔力 | 专注 / 韧性 |
| 猎人的箭 / 女巫的结界 / 女巫的药剂 | 一支旧箭 / 荆棘里的灯 / 琥珀药瓶 |
| 夜袭伤害 | 漏项扣生命 |

卡面立绘裁掉了底部写着角色名的名牌，只留人物，名字由 App 自己标。
想改回去：角色名在 `Core/Models.swift` 的 `ROLES`，字条文案在 `Core/Rules.swift` 的 `Council`，夜谈文案在 `Core/KeyCase.swift`。

### 3. 地图是图，而且靠任务解锁

地点只认“整件做完”的任务数（`Core/Rules.swift` 的 `Atlas`）：

| 做完 | 开门的地点 | 开放的功能 |
| --- | --- | --- |
| 0 | 任务板、木偶剧场、火堆、钟楼 | 待办、反向体验前三幕、三张字条、单机夜谈、回声总览 |
| 1 | 观星台 | 决策档案 · 夜谈第二手「对照前后发言」 |
| 2 | 剧场后台 | 反向体验后三幕（像素、反驳、第 N 次） |
| 3 | 回声廊 | 任务与选票对照 · 夜谈第三手「追问票型」 |
| 4 | 渡口 | 联机夜谈 |
| 6 | 镜湖 | 下次验证 · 夜谈第四手「排除矛盾」 |

登记完成时如果有新地点开门，会有提示和音效；再打开地图时，新开的图钉会亮一下。
演示时可以在“设置”里打开 **演示：地图全部开门**。

### 4. 不同完成情况，经验不同

登记完成时逐条列出（`Rules.xpParts`）：

| 项目 | 经验 |
| --- | --- |
| 必做 / 额外 | 6 / 8 |
| 专注（必做） | + 专注值 |
| 寻迹人同行（必做） | +2 |
| 实际用时 ≤ 预计的 80% | +2 |
| 实际用时在预计的 80%–120% | +3 |
| 实际用时在预计的 120%–150% | +1 |
| 开了计时（≥ 1 分钟） | +1 |
| 一次都没选过“继续准备” | +1 |
| 继续准备 2 次以上 | 每多一次 −1，最多 −3 |
| 亲手剪对过这件事的一张字条 | +1 |
| 只做完一部分 | 以上合计减半 |

“只做完一部分”仍算漏项，但收工时只扣一半生命，之后可以补完。
收工时另有当日加成：必做一件不漏 +4，完成过半 +1。

### 5. “反人类”落到主流程的细节里

界面会在四个地方使坏（设置里可以关）：

- **写待办**：停笔两秒，界面递上一句补全（“……等有空再说”），不理它就自己写进标题。
- **登记完成**：最显眼的是一个“一键全部打勾”按钮，真正的确认要长按。
- **剪字条**：界面预选一张（不是对的那张），8 秒后替你下剪。
- **收工**：有一个默认勾好的“把没做完的也记成做完”。

每次亲手拦下或被带走都会记一笔，首页和回声里的 **人类含量** 就是“亲手决定的次数 ÷ 被试探的次数”。

### 6. 音效更多

48 个音效全部是代码现算的波形（`Audio/Synth.swift`），不带音频文件。
网页版的 33 个逐个移植，另加了钉任务、剪字条、盖章、翻纸、刻度、开关、回血、连续达成、迷雾散开、门没开、诱饵 / 拦下 / 被带走等。
按钮按下、输入、拖动山庄、长按确认（音调逐渐升高）都有声音，并配了触感反馈。

### 7. 小字

各处的免责说明、英文眉标、重复解释都删了，每个页面只留一句必要的话。

## 需要你们确认的事

- **立绘、全景图和默认音乐** 是从网页里原样搬过来的。默认音乐是一首商业曲目的 30 秒试听，上架前请确认授权，或者换成自己的音频（App 里可以导入）。
- **联机夜谈** 需要你们原来那套房间服务（`/api/rooms`）。在联机页填服务地址即可；局域网的 `http://` 地址已放行，公网地址需要 `https://`。
- 声音用的是 `.playback` 会话：静音键不会让它消音，也不会打断别的 App 的音乐。想跟随静音键，把 `Audio/SoundEngine.swift` 里的 `.playback` 改成 `.ambient`。
